# Daily Analyst Mini Challenge

## Project Overview
A beginner-friendly Data Analyst project using the Sample Superstore dataset.

## Tools & Technologies
- Microsoft Excel
- Python
- Pandas
- Matplotlib
- VS Code

## Dataset
Sample Superstore dataset containing 9,994 records and 13 columns.

## Business Questions
1. What is the total sales?
2. What is the total profit?
3. Which category has the highest sales?
4. Which region has the highest sales?
5. Which sub-category has the highest sales?

## Key Findings
- Total Sales: 2,297,200.86
- Total Profit: 286,397.02
- Highest Sales Category: Technology
- Highest Sales Region: West
- Highest Sales Sub-Category: Phones

## Project Files
- `dataset/` – Original dataset
- `analysis.py` – Python analysis
- `summary.md` – Project summary
- `README.md` – Project documentation

## Conclusion
This project demonstrates basic data analysis using Excel and Python.
