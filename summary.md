# Daily Analyst Mini Challenge

## Project Overview
This project analyzes the Sample Superstore dataset
using Excel and Python.

## Tools Used
- Microsoft Excel
- Python
- Pandas
- Matplotlib
- VS Code

## Key Findings
- Total Sales: 2,297,200.86
- Total Profit: 286,397.02
- Highest Sales Category: Technology
- Highest Sales Region: West
- Highest Sales Sub-Category: Phones

## Conclusion
Technology generated the highest category sales.
The West region generated the highest regional sales.
Phones generated the highest sub-category sales.
